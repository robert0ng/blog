2020年進入將來銀行，是我的第一次踏入銀行業。

一開始的目標是挑戰從零開始打造銀行 App，過程中熟悉各種銀行提供的業務，其背後的 know-how 及思維，當然如果順道認識了一些人，經歷了一些奮鬥更好。

至今看來，美好的一役已經打過，戰友紛紛離開各奔東西，經歷過前期的開發奮戰大成長期，至 2026 年各項業務已進入穩定成長期，開發節奏跟目標已經跟初期的籌備處不可同日而語。

記得當初華南銀行來上任的董事長許柏林說：「你們很辛苦！一兩個月就要上一版新版！要加油！」我心想：以科技新創的節奏大概是兩三週就要上新版，這已經是輕輕鬆鬆游刃有餘的節奏了！但牽涉到金錢，跟後端龐大的分支系統要維護、要更新，每一動都不能輕忽的！所以每往前踏一步，還是穩健一些，踏實得走，在金融產業才能走得遠！不同產業的調性，還是得身在其中才能體會。

以上廢話分隔線

以下列出這段期間經手重大的開發項目：

## 1. 架構奠基與核心銀行功能建置

- 主導 MotionLayout 應用於 Debit Card 翻轉動畫可行性研究及實作：研究側邊卡片動態設計、實作翻轉手勢與監聽器，解決翻轉時卡片消失、彈窗遮擋等顯示問題，成為 App 招牌互動效果之一，並持續維護至今
- SdkManager/SdkWrapper 架構：整合第三方 SDK（OCR 等），用共用架構隔離各家 SDK 實作細節，降低耦合、方便注入使用
- BaseToolbar 共用元件：跨模組共用的 toolbar 元件，處理標題置中、顯示/隱藏、與頁面轉場動畫協調
- MVVM + 多模組架構：基礎架構建設，業務模組化拆分
- Session Timeout 機制：閒置逾時彈窗、token 過期自動登出
- 開戶流程模組：從零打造開戶共用元件，並整合 SDK 進行身分證正反面辨識驗證，後續共用至其他證件上傳流程（如變更聯絡資訊時的證件確認）
- 核心銀行功能：登入、帳戶、信用卡、定存、轉帳、交易頁面從零建置

## 2. 身分驗證與雙因子驗證整合

- 身分驗證 SDK 版本迭代維護
- 登入與生物辨識整合：Pattern 設定、指紋/臉部辨識、快速登入判斷邏輯
- 全 App 雙因子驗證元件化：轉帳、外匯、信用卡等各交易確認頁串接完成雙因子驗證
- 監控與追蹤：加入事件追蹤機制，加速排查問題

## 3. 採用 Jetpack Compose UI 並逐步遷移

- 早期採用：自訂輸入元件、商品搜尋頁率先導入
- 外匯模組導入：定存/外幣產品畫面移植整合
- 擴大應用：交易報表日曆、外幣產品畫面陸續改寫
- 信貸與轉帳：信貸首頁、無卡提款、排程轉帳結果頁改寫
- 雙因子驗證重構：流程重構並將舊版畫面轉換為新框架

## 4. 其他金融產品項目

- TW Pay 支付功能
  - 重構支付流程，調整掃碼頁面支援 Edge To Edge 
  - 桌面 Widget/捷徑：主畫面 Widget 與 App Shortcut 快速付款入口

- 基金/股票/ETF 理財商品購買流程
  - 元件整併/重構：抽出共用元件跨基金/股票/ETF 共用
  - 扣款帳戶邏輯：無可用扣款帳戶提示，支援多幣別確認頁
  - 美股/ETF 強化：小數點輸入、輸入狀態保留、金額驗證

- NFC 讀卡整合
  - 整合 NFC 讀卡 SDK 至 App
  - 建立測試流程驗證讀卡功能
  - 調整讀卡介面樣式

- 維護並更新 Kotlin Native library 
  - 此為 Android/iOS Team 共用的 API data layer

## 5. 撰寫並維護開發工具 及 Play Store 上架規範等開發環境

- 導入 API 檢視工具，供 QA 及 SA 各方快速排查內容及錯誤
- PR 自動發布腳本
  - PR 內容自動填寫：依單號抓取標題、更新說明章節、預設指定 Branch
  - 整合 Azure Devops 自動建立 PR
  - 團隊通知：整合訊息通知，含斷線偵測與重試機制
- CI/CD
  - 依據環境 設定多組 Pipeline 產出成品及漏洞檢測報告
  - 安裝設定 Mac 供 CI 使用，並文件化交由團隊共同維護
  - 指導同事於 pipeline 加上發版通知功能
  - 根據更新資安守則，持續維護上架規範及帳號控管，同樣文件化交由團隊共管
