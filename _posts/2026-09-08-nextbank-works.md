2020年進入將來銀行，是我的第一次踏入銀行業。

一開始的目標是挑戰從零開始打造銀行 App，過程中熟悉各種銀行提供的業務，其背後的 know-how 及思維，當然如果順道認識了一些人，經歷了一些奮鬥更好。

至今看來，美好的一役已經打過，戰友紛紛離開各奔東西，經歷過前期的開發奮戰大成長期，至 2026 年各項業務已進入穩定成長期，開發節奏跟目標跟當年已經不可同日而語。

以下列出這段期間經手重大的開發項目：


## 1. 架構奠基與核心銀行功能建置

- MotionLayout 可行性研究與 Debit Card 翻轉動畫：研究側邊卡片動態設計、實作翻轉手勢與監聽器，解決上線後翻轉時卡片消失、彈窗遮擋等顯示問題，成為 App 招牌互動效果之一，並持續維護至今
- SdkManager/SdkWrapper 架構：整合第三方 SDK（OCR 等），用共用架構隔離各家 SDK 實作細節，降低耦合、方便注入使用
- BaseToolbar 共用元件：跨模組共用的 toolbar 元件，處理標題置中、顯示/隱藏、與頁面轉場動畫協調
- MVVM + 多模組架構：基礎架構建設，業務模組化拆分
- Session Timeout 機制：閒置逾時彈窗、token 過期自動登出
- 開戶流程模組：從零打造開戶共用元件，並整合 SDK 進行身分證正反面辨識驗證，後續共用至其他證件上傳流程（如變更聯絡資訊時的證件確認）
- 核心銀行功能：登入、帳戶、信用卡、定存、轉帳、交易頁面從零建置

## 2. 身分驗證與雙因子驗證整合

- 身分驗證 SDK 版本迭代維護
- 登入與生物辨識整合：Pattern 設定、指紋/臉部辨識、快速登入判斷邏輯
- 全 App 雙因子驗證元件化：轉帳、外匯、信用卡等各交易確認頁串接完成雙因子驗證
- 監控與追蹤：加入事件追蹤機制，加速排查問題

## 3. Jetpack Compose UI 遷移

- 早期採用：自訂輸入元件、商品搜尋頁率先導入
- 外匯模組導入：定存/外幣產品畫面移植整合
- 擴大應用：交易報表日曆、外幣產品畫面陸續改寫
- 信貸與轉帳：信貸首頁、無卡提款、排程轉帳結果頁改寫
- 雙因子驗證重構：流程重構並將舊版畫面轉換為新框架

## 4. 其他

- TW Pay 支付功能
  - 重構支付流程，調整掃碼頁面支援 Edge To Edge 
  - 桌面 Widget/捷徑：主畫面 Widget 與 App Shortcut 快速付款入口

- 基金/股票/ETF 理財商品購買流程
  - 元件整併/重構：抽出共用元件跨基金/股票/ETF 復用
  - 扣款帳戶邏輯：無可用扣款帳戶提示，支援多幣別確認頁
  - 美股/ETF 強化：小數點輸入、輸入狀態保留、金額驗證

- NFC 讀卡整合
  - 整合 NFC 讀卡 SDK 至 App
  - 建立測試流程驗證讀卡功能
  - 調整讀卡介面樣式

- 維護並更新 Kotlin Native library 
  - 此為 Android/iOS Team 共用的 API data layer

## 8. 撰寫開發工具

- 推動 Chucker 工具導入，供 QA 及 SA 各方快速排查 API 內容
- PR 自動發布腳本
  - 建立自動化腳本：自動偵測分支、建立 PR
  - 認證資訊管理：Token 移至獨立設定檔，避免進版控
  - PR 內容自動填寫：依單號抓取標題、更新說明章節
  - 團隊通知：整合訊息通知，含斷線偵測與重試機制

## 9. 維護 Pipeline 

- 依據 SIT/UAT/PROD 設定多組 Pipeline 產出成品及漏洞檢測報告
- 設定 Mac 中 Azure agent 供 Pipeline 呼叫使用
- 指導同事於 pipeline 最後一步加上發版通知功能
